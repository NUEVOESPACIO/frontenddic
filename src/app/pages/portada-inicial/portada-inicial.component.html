Bienvenid@ a mi Portfolio
Gracias por visitarme

¡Hola! Mi nombre es Sebastián y te presento el proyecto con el que finalicé y aprobé el programa Argentina Programa en el año 2022. Se trata de un portfolio web desarrollado como trabajo final, con el objetivo de aplicar de manera práctica los contenidos aprendidos durante el curso.

Este portfolio es una muestra ficticia e incompleta, es decir, los datos no se completaron en su totalidad y son demostrativos y académicos.

Tecnologías usadas

- FrontEnd: Angular con JavaScript. Repositorio: frontenddic (frontend)
- BackEnd: Java con Spring Boot (NetBeans). Repositorio: BackEndEnero (backend)
- Base de datos: MySQL (Clever Cloud)
- Hosting FrontEnd: Firebase
- Servidor BackEnd: KOYEB
- Repositorios: GitHub (deploy automático en BackEnd, manual en FrontEnd)

Contenidos aplicados

- Programación Orientada a Objetos
- Arquitectura por capas
- Autenticación y Autorización JWT
- Uso de JPA y manejo de Entities
- Integración entre FrontEnd y BackEnd
- Consumo de servicios REST
- Utilización de repositorios remotos (GitHub)

Proyecto personal — Simulador gravitacional de cuerpos celestes

Estado actual: aproximadamente 50% completado

Actualmente me encuentro desarrollando un simulador físico orientado al comportamiento gravitacional de múltiples cuerpos celestes bajo las leyes de Newton. El proyecto está inspirado en el conocido problema de los N-Cuerpos (N-Body Problem).

Arquitectura y tecnologías:

  • BackEnd con Java + Spring Boot
  • Persistencia con JPA y MySQL
  • JWT Token con manejo de Usuarios y Roles
  • FrontEnd con React + TypeScript
  • Diseño Tailwind
  • Motor de simulación desarrollado en JavaScript
  • Renderizado gráfico utilizando Canvas
  • Testing en desarrollo
  • Estado del Proyecto: Be en GitHub, en proceso (Mayo 2026) de desarrollo FrontEnd

Deploy planificado:

  • BackEnd → Render
  • FrontEnd → Vercel
  • Base de Datos → Supabase

Proyecto personal — Análisis de carteras de inversión

Estado actual: aproximadamente 30% completado

Proyecto orientado al análisis estadístico de carteras de inversión de acciones y ETFs, enfocado principalmente en el estudio de correlaciones y balance de riesgo.

Objetivos principales:

  • Obtención de matrices de correlación de Pearson
  • Análisis de retornos históricos
  • Balance y diversificación de cartera
  • Detección de instrumentos con mejor ventana de oportunidad

Tecnologías utilizadas:

  • Yahoo Finance API
  • TypeScript
  • React
  • Node.js
  • Lectura de archivos Excel mediante librerías especializadas

Actualmente el proyecto continúa en entorno local mientras sigo desarrollando funcionalidades y arquitectura.

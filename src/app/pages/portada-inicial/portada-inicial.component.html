Bienvenid@ a mi Portfolio
Gracias por visitarme

¡Hola! Mi nombre es Sebastián y te presento el proyecto con el que finalicé y aprobé el programa Argentina Programa en el año 2022. Se trata de un portfolio web desarrollado como trabajo final, con el objetivo de aplicar de manera práctica los contenidos aprendidos durante el curso.

Este portfolio es una muestra ficticia e incompleta, es decir, los datos no se completaron en su totalidad y son demostrativos y académicos.

Tecnologías usadas

- FrontEnd: Angular con JavaScript
- BackEnd: Java con Spring Boot (NetBeans)
- Base de datos: MySQL (Clever Cloud)
- Hosting FrontEnd: Firebase
- Servidor BackEnd: KOYEB
- Repositorios: GitHub (deploy automático en BackEnd, manual en FrontEnd)

Contenidos aplicados

- Programación Orientada a Objetos
- Arquitectura por capas
- Autenticación y Autorización JWT
- Uso de JPA y manejo de Entities
- Integración entre FrontEnd y BackEnd
- Consumo de servicios REST
- Utilización de repositorios remotos (GitHub)
